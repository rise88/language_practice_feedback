# Vocalis feedback

Public place for **bugs** and **petitions** (feature / content asks) about [Vocalis](https://language-practice-three.vercel.app).

You need a free [GitHub account](https://github.com/signup). You do **not** need access to the private app source.

## How to file

1. Open **[New issue](https://github.com/rise88/language_practice_feedback/issues/new/choose)**
2. Pick **Bug** or **Petition / idea**
3. Fill the form and submit

Or from the app: **Aide → Retours sur GitHub**.

## Labels (we use these when triaging)

| Label | Meaning |
|-------|---------|
| `bug` | Something broken |
| `petition` | Feature or content request |
| `needs-info` | Waiting on more detail from you |
| `accepted` | We’ll work on it |
| `wontfix` | Not planned |

## Privacy

Do not post passwords, personal data, or private class materials. Progress lives in your browser / account — we don’t need your deck JSON unless you choose to share a **redacted** example for a bug.
